# JEV 个人交易助手

## 实施边界与设计

目标：按 `output/prototypes/v1` 四张已确认原型，交付本机可用的大盘、滚动选股、个股研究、推荐验证和独立模拟账本。现有五分钟监控与通知链路不改动。

- 使用 Python 标准库 HTTP 服务、SQLite 与浏览器原生 ES modules，无新增生产依赖。此仓库尚无 React/Vite，零依赖限制下保持组件化模块实现。
- 深海蓝侧栏 236px，冷白页面、白色面板、蓝色交互；涨红跌绿、风险琥珀色。标题 30px、正文14px、辅助12px；8px圆角、16/24px间距。导航、表格、条件面板、图表复用。
- 大盘为四指标、市场图表与情绪左右分栏、策略横条、候选与风险底栏。选股为排名表与详情双栏。个股为图表/决策/营收/公告。验证严格分开推荐走势和模拟收益。
- 真实数据缺失时保留相应版面并明确缺口；不会复制原型中的演示数字或伪造 K 线、营收、收益。归档采样线不是逐笔分时。

数据边界：读取 `STOCK_DATA_DIR` 下已有报告和研究归档，仅白名单字段进入页面。私密凭证不读取到页面。新账本写入 `STOCK_DATA_DIR/assistant/ledger.sqlite3`，绝不修改 plan、真实持仓、旧执行账本。推荐事件唯一编号去重，同一股票不同时间/版本保留；失败样本不删除。

模拟边界：手动选择有效正式推荐创建独立模拟委托，随后有效行情才可能判定成交；涨停排队不能从五分钟快照证明成交。T+1、整手、预算、费用与未成交资金均保留。不是收益回测，不冒充真实成交。历史推荐只导入跟踪，不追溯制造交易。国金证券仅有禁用适配接口，真实交易始终关闭。

安全边界：服务仅监听127.0.0.1，校验Host、Origin和会话写入令牌；不提供任意文件读取、命令执行或通用代理。输入长度/类型校验，DOM以文本渲染外部信息。没有实盘开关。

实施：先定义归档与账本契约 → 测试数据适配/模拟不变量 → 本地API与原型页面 → 桌面手机浏览器验证 → 独立审查。文件责任：data.py归档；ledger.py模拟；market_data.py行情；server.py与static主线程整合。

验证：定向pytest、安全HTTP测试、现有回归、浏览器交互和视觉对照。回滚只需停止服务；新增账本保留，原监控不受影响。财务源、实时行情源可能限流，页面明确显示更新时间和错误；快照不具备逐笔成交证明力。

## 启动

```sh
STOCK_DATA_DIR=/Users/habitat/ai_project/stock_anaylze /Users/habitat/miniforge3/bin/python3 -m assistant.server
```

打开 http://127.0.0.1:8766 。刷新只读取既有分析归档并获取行情，不启动重复监控、不推送消息、不调用模型重做交易判断。

技术研究辅助，不构成投资建议。

## 策略展示与扩展

“我的策略”通过只读 `/api/strategies` 显示当前陈小群思路规则化研究框架，以及未启用的巴菲特价值研究模板。目录位于 `assistant/strategies.py`，每个策略具有独立 ID、说明版本、周期和选股/参与/退出/风控/数据/验证字段；新增目录项即可由界面自动呈现。目录加载时校验结构，返回副本避免共享修改。

目录的 `current_strategy_id` 仅标识现有研究框架，不是执行引擎开关。查看模板不会修改 plan、既有推荐、模拟账本或监控。后续实际切换需另行实现策略专属数据与评估逻辑、历史版本映射和验证；不能只改目录标识就宣称执行了新策略。说明阈值是现有规则摘要，实际参数以交易计划与当轮结果为准。历史推荐保留来源版本，不追溯贴上新策略标签。

## 选股来源与名单变化

选股表、个股页和推荐记录显示原归档的策略 ID / 名称 / 版本。来源标签使用独立视图，不变更已写入账本的推荐内容。历史没有完整策略证据时显示“来源未标注”，不按当前目录回填。相同股票在不同轮次保留各自来源。

“滚动选股 → 名单变化”可选择前后两份研究归档，查看新增、保留、状态/归属变化与移出，显示逐股前后来源和归档理由。当前提供最多100份研究快照对比；失败或不完整快照不推断移出。策略或版本变更与同策略跨轮变化分开标识；跨时间对比不是固定行情下的因果验证。

未来 cycle 报告自动记录 `strategy`：已知执行框架 ID、名称、规则文件和规范的指纹、原始计划指纹。指纹变化只表示输入/代码变化，不等于策略性能改善，也不接受自由填写的计划名称冒充其他策略。滚动研究须使用 `strategy_identity(original_plan, scope='rolling', selector_revision=...)`，在内存研究副本生成前记录来源，并按研究筛选逻辑更新版本。缺失来源时保留错误提示。真实策略引擎切换和同一行情重算仍需各策略实现及验证。
